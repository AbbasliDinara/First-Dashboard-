# 📊 HR Data Analytics Dashboard

## 📌 Project Overview
This interactive **HR Data Dashboard** provides a concise overview of organizational demographics, salary distributions, performance bonus categories, and regional employee allocation.

---

## 🔑 Key Metrics & Highlights
* **Total Headcount (İşçi sayı):** 26 employees
* **Average Salary (Ortlama maaş):** $2.44K
* **Average Age (Ortlama işçi yaşı):** 35 years

---

## 📊 Visual Breakdown
* **Bonus Category Distribution:** Categorizes staff by bonus tiers (Yüksək, Orta, Aşağı).
* **Average Salary by Department:** Compares average salary across departments, with Maliyyə (Finance) leading the pay scale.
* **Regional Employee Distribution:** Donut chart mapping workforce concentration across regions (Bakı: 38.46%, Gəncə: 19.23%, Lənkəran, Şamaxı, Qəbələ).
* **Interactive Slicers:** Filtering panel by Department (**Şöbə**) and Region Code (**Region Kodu**).

---

## 🎨 Visuals Used
* **Card Visuals:** High-level metric summaries (Headcount, Average Salary, Average Age).
* **Clustered Column Chart:** Employee count by Bonus Category.
* **Horizontal Bar Chart:** Departmental average salary comparisons.
* **Donut Chart:** Regional workforce distribution percentages.
* **Slicers:** Dropdown filters for interactive dynamic analysis.
